# Smart Contract Gas Optimization Simulator

This example simulates EVM gas costs for DeFi savings contracts like Spark Savings. It contrasts unoptimized contract patterns with optimized techniques such as storage slot packing, SLOAD memory caching, and batched multicall execution.

## Language

`python`

## How to Run

Run with `python3 gas_optimizer.py` using Python 3.8+.
